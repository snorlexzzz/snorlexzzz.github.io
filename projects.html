Central Bank Sentiment Analysis, Feb 2025

This project studies how central bank communications influence interest rate decisions. It focuses on speeches from U.S. Federal Reserve Chairs and European Central Bank officials. Using FinBERT, a financial sentiment analysis model, speeches are classified as Hawkish (Bullish), Neutral, or Dovish (Bearish) (multi-class classification). The goal is to test whether the sentiment expressed in these speeches aligns with the subsequent interest rate changes, providing insight into how monetary policy signals are communicated and interpreted.

Image Classification using Convolutional Neural Network for 3D reconstruction, Apr 2024

This project explored how machine learning can assist 3D reconstruction from unstructured 2D image collections. Since determining whether two images depict the same scene is a key first step, we trained and compared four neural network models: a custom CNN, VGG16, VGG19, and DenseNet121 and use them to classify image pairs as belonging to the same or different scenes. Using labeled image data, we evaluated their accuracy to identify the most effective model for supporting downstream 3D spatial reconstruction tasks, which are essential in fields such as virtual reality, urban planning, and autonomous navigation.
